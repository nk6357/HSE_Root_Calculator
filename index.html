Главная Калькулятор

Добро пожаловать в HSE Калькулятор корней!

Вычисляйте корни чисел быстро и с заданной точностью. Калькулятор поддерживает обычные и комплексные числа, аналитическую и численную форму ответа.

О проекте

HSE Калькулятор корней — это проект, предназначенный для вычисления корней чисел с возможностью выбора точности и формы ответа.

Как пользоваться калькулятором

Ознакомьтесь с правилами ввода данных. Введите число, выберите точность и форму ответа, затем нажмите кнопку «Вычислить». Результат будет отображен на экране.

Правила ввода данных в калькулятор

  • Дробное число вводится только через точку “2.25”
  • Логарифм: в скобках указывается аргумент “log3(9)”
  • Тригонометрическая функция “cos(x)” угол писать в градусах
  • Для выражений использовать только знаки “ + - * / ^ ” выражения записывать без пробелов
  • Для комплексных чисел использовать английскую букву “i”
  • Число ПИ писать заглавной английской буквой “P”
  • Степень в выражениях по типу log2(8) и cos(240) указывать так: log2^2(8), cos^3(240)
