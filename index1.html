Welcome to the HSE Root Calculator!

Calculate square roots quickly with your chosen precision. The calculator supports real and complex numbers and provides analytical and numerical forms of the result.

About the project

The HSE Root Calculator is a project designed to calculate square roots with the option to choose the precision and result form.

How to use the calculator

Please review the input rules. Enter a number, choose the precision and result form, then click the “Calculate” button. The result will be displayed on the screen.

Calculator input rules

  • Enter decimal numbers using a period only: “2.25”
  • Logarithm: specify the argument in parentheses: “log3(9)”
  • For the trigonometric function “cos(x)”, enter the angle in degrees
  • Use only the symbols “ + - * / ^ ” in expressions and enter expressions without spaces
  • For complex numbers, use the lowercase English letter “i”
  • Write pi as the uppercase English letter “P”
  • For exponents in expressions such as log2(8) and cos(240), use this format: log2^2(8), cos^3(240)
